# Доступ тестовой версии

Все операции требуют действующей серверной сессии и активного членства организации. Членство перепроверяется на каждом запросе. Запрещённые чтения дают 403, запрещённые команды — 409 с объяснением. Системный оператор не получает бизнес-доступ. Учётные записи клиентов и художников пока отсутствуют.

| Роль | Доступ |
|---|---|
| owner | Все реализованные разделы, создание тарифов, финансовые команды, аудит |
| admin | Клиенты, представители, занятия, записи, абонементы, очередь, присутствие; чтение картин/выставок |
| curator | Картины, выставки, индивидуальные отправки/приём и основания прав |
| cashier | Платежи, возвраты, начисления, распределения; чтение тарифов/абонементов |
| teacher, analyst | Пока запрещены все бизнес-разделы: ограничения по назначенным группам и полям ещё не реализованы |

Данная матрица — ограничение тестовой реализации; она не утверждает окончательную матрицу Q-14. Управление членствами, приглашения, восстановление пароля, MFA и защита последнего владельца ещё не доступны через приложение. Не меняйте роли напрямую в production — production запрещён схемой Helm values.
