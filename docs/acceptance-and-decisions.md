## 1. Условия проведения

Стенд ___; commit/релиз ___; дата ___; принимающий ___; тестировщик ___. Используются синтетические люди и файлы, две организации A/B, разные роли, два филиала, два преподавателя, помещение с ограниченной вместимостью, несколько тарифов и 5 картин. ## 4. Уточнение требований и управление изменениями

Для Q-03 достаточно использовать уже найденных респондентов. Уточняются их реальные последние случаи: запись/отмена, сверка оплаты, поиск картины, отправка/возврат, ошибки и затраты времени. Для каждого правила нужен пример обычной и исключительной ситуации. Цитаты и готовность платить фиксируются только по фактическим разговорам.
